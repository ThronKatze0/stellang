# Made for stellang

**Stellang Nebula** (dark) and **Stellang Daybreak** (light) color each kind of name differently:

- functions in starlight gold, **bold** where they're declared
- structs in cyan, enums and their `.Variants` in aurora green
- `var`s <u>underlined</u>, because they can change; parameters in *italic pink*
- the error-flow marks `?` `!` `??` `?.` in bright red, so you see where errors travel
- `⭐` braces in gold

Any other theme works too: the extension gives every token a standard scope.
