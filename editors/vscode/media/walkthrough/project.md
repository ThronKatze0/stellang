# Start from a template

**stellang: New Project…** creates a folder with a working program:

| template | what's in it |
|---|---|
| ⭐ Hello, stars | structs, optionals, interpolation |
| Web server | routes, middleware, `listen` |
| JSON API + WebSockets | a todo API with a live feed and a web page |
| Data modeling | enums with data, methods, exhaustive `match` |
| Command-line tool | files and error handling |

Or open any folder with `.st` files: the **stellang** sidebar lists its programs, types and HTTP routes.
